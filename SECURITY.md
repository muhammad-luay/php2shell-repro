# Security and responsible use

This repository is defensive material. It contains no exploit code and must not
be used to test systems without explicit authorization.

- Use the lab evidence only on systems you own or are authorized to test.
- Report vulnerabilities to the PHP security team or the affected vendor.
- Do not publish or mirror upstream packages that carry private/embargo terms.
- Do not send working PoCs to third parties; send patch-level guidance and
  detection notes instead.

For PHP core issues, use the PHP project’s security reporting process and the
advisories linked in [docs/UPSTREAM.md](docs/UPSTREAM.md).
